AI 로봇 프로젝트 아이디어 도출 & 프롬프트 가이드

복잡한 레고 메커니즘 조립은 필요 없습니다! 모터와 센서가 동작하는 원리를 이해하고, 안티그래비티(AI 코딩 도구)를 적극 활용하여 2~3시간 안에 동작하는 엣지 AI 로봇을 구현해보세요.

학생용 프로젝트 설계 핵심 개념 4가지

1. 문제 정의: "불편함"을 "AI가 할 일"로 바꾸기

그냥 "AI 만드는 프로젝트"라고 하면 범위가 너무 넓어 무엇부터 코딩해야 할지 몰라요. "지금 내 일상이나 학교에서 어떤 점이 불편한가?(현재 상황)"를 찾고, "AI가 어떻게 도와줄 수 있을까?(원하는 상황)"를 구체적으로 적어봅시다.

💡 일반 코딩 vs AI 코딩의 차이:
• 일반 코딩 (if-else): "버튼을 누르면 LED가 켜진다"처럼 규칙이 명확할 때.
• AI 코딩: "카메라를 보고 물체를 맞춘다", "쓰레기 종류를 구분한다"처럼 인공지능 패턴 인식이 들어갈 때!
2. 현실적인 목표 설정: 복잡한 조립은 NO! 2~3시간 코딩에 집중

라즈베리파이는 손바닥만 한 초소형 컴퓨터예요. 복잡한 기계 메커니즘을 조립하는 데 시간을 쏟기보다, "카메라 AI 인식 ➔ 모터/센서 반응"이 기본 동작하는 것에 집중하여 2~3시간 안에 완성하는 것이 목표입니다.

❌ 나쁜 목표: "완벽한 자율주행 거대 로봇 조립하기" (시간 부족)
⭕ 좋은 목표: "카메라로 페트병/캔을 구분하고 2초 안에 모터가 동작한다."
3. 기능 나누기: 꼭 필요한 것(Must) vs 되면 좋은 것(Nice)

처음부터 거창하게 만들려고 하면 중간에 포기하게 돼요. "이것만은 무조건 실행되어야 해!(핵심 기능)"를 먼저 안티그래비티 코딩으로 완성하고, 시간이 남으면 "이것도 되면 좋겠다(추가 기능)"를 하나씩 붙여나가는 게 개발의 정석입니다.

🗑️ 예시 (스마트 쓰레기 분류기):
• 필수 기능 (Must): 카메라로 쓰레기(플라스틱/캔) 인식하기, 모터 구동
• 추가 기능 (Nice): 쓰레기 접근 시 거리 센서로 LED 자동 켜기
4. 성공 기준: AI 도구(안티그래비티)에게 검사받을 기준 만들기

여러분이 작성한 개발계획서를 안티그래비티 AI 도구에게 주면 파이썬 코드를 즉시 짜줄 거예요. 완성된 코드가 잘 작동하는지 '2초 이내 반응하는가?', '10번 중 8번 이상 맞추는가?'처럼 숫자로 검증할 수 있는 기준을 정해두어야 합니다.

• 반응 속도: 물체를 비춘 후 2초 이내 결과 출력
• 정확도: 10번 중 8번 이상(80%) 정확히 분류
• 안정성: 다운되지 않고 연속 10회 정상 작동

안티그래비티 적극 활용 프롬프트 3단계

안티그래비티 AI 코딩 도구에 아래 프롬프트를 그대로 복사해서 붙여넣고 질문해보세요! 2~3시간 내 완성 가능한 최적의 코드를 생성해줍니다.

1단계: 아이디어 도출 프롬프트
아이디어 추천
Prompt Step 1 - Idea Generation (2~3h Limit) 
나는 라즈베리파이4와 레고 스파이크 부품, 안티그래비티(AI 코딩 도구)를 활용해 2~3시간 만에 AI 로봇 프로젝트를 완성해야 하는 고등학생이야. 복잡한 기계 조립 없이 기본 모터와 센서 동작 연동 위주로 만들 수 있는 독창적인 AI 디바이스 아이디어 3가지를 추천해 줘.

핵심 AI 부품: 라즈베리파이 4B, V2 카메라, Google Coral TPU (빠른 이미지 인식)
구동 및 센서 부품: BuildHAT, 레고 스파이크 모터 2개, 거리센서, 힘센서, 컬러센서
시간 제약: 2~3시간 안티그래비티 AI 코딩 + 테스트 완성이 목표 (복잡한 레고 조립 제외)

AI 이미지 인식(Coral TPU)과 레고 모터/센서 동작이 서로 연동되는 재미있는 아이디어로 추천해 주고, 각 아이디어별로 **[무엇을 인식하는지], [레고 모터가 어떻게 움직이는지]**를 설명해 줘.
2단계: 2~3시간 내 구현 가능성 검증 프롬프트
난이도 검증
Prompt Step 2 - Feasibility Verification 
추천해 준 아이디어 중 '[선택한 아이디어명]'을 만들고 싶어.

내가 가진 레고 모터 2개와 [선택한 센서]만으로 복잡한 조립 없이 2~3시간 안에 파이썬 코드로 검증할 수 있을까?
Coral TPU에서 바로 돌릴 수 있는 기본 모델(예: MobileNet 객체 탐지, 이미지 분류 등)로 구현이 가능한 구조야?
개발 및 테스트할 때 가장 시간이 오래 걸릴 것 같은 고비(오류 가능성)는 뭐야?
3단계: 안티그래비티 제출용 개발계획서 생성 프롬프트
계획서 자동 생성
Prompt Step 3 - Project Plan Generation 
좋아, 이 아이디어로 정했어! 안티그래비티(AI 코딩 도구)에 입력해서 Python 코드를 자동 생성할 수 있도록 프로젝트 개발 계획서를 작성해 줘.

OS: Raspberry Pi OS Bullseye 32bit
라이브러리: PyCoral / tflite_runtime (Coral TPU용), buildhat (레고 제어용)
개발 시간: 2~3시간 (기본 모터/센서 동작 중심)

필수 기능:
- 카메라로 이미지를 받아 Coral TPU로 실시간 추론
- 인식 결과에 따라 BuildHAT으로 연결된 레고 모터 동작
- [선택한 레고 센서]를 활용한 예외 처리 또는 보조 동작

안티그래비티 적극 활용 꿀팁

안티그래비티 도구에 개발계획서 양식을 그대로 주면 파이썬 라이브러리(OpenCV, PyCoral, buildhat)가 정교하게 결합된 실행 코드를 즉시 작성해줍니다! 코드가 작동하지 않거나 에러 메시지가 뜨면 에러 화면을 안티그래비티에 그대로 전달하여 1분 만에 디버깅을 완료해보세요.
