# AI Robot Master — Classroom Guide v2 (review preview)

## 검토 목적

기존 GitHub Pages 기본 사이트를 건드리지 않고, `v2/`에서 5개 메뉴와 8단계 설치 가이드의 UX를 검토하기 위한 정적 프런트엔드입니다.

- `index.html`: 독립 실행 가능(추가 서버 불필요)한 SPA 진입점
- `assets/styles.css`: 다크/라이트 및 PC/모바일 반응형 스타일
- `assets/app.js`: 메뉴·설치 단계·완료 체크·명령어 복사·오류 해결·자료실 콘텐츠
- `assets/favicon.svg`: 자체 제작 벡터 아이콘

압축을 풀고 `v2/index.html` 파일을 Chrome으로 여세요. 기존 학습 페이지는 현재 공개된 사이트의 절대 URL로 연결하므로 압축파일에서도 이동할 수 있습니다. Google Slides 등 외부 링크는 인터넷 연결이 필요합니다.

## 검증/보류

- RC6 학생용 공식 문서에서 설치 순서 `[1] SD카드 준비 → [2] Windows 인터넷 공유 → Pi 부팅 → [3] 오프라인 AI 설치 → [4] 최종 진단` 확인.
- RC7 원본 ZIP의 내부 Setup CMD 파일명/메뉴/재부팅/최종 진단 로그 및 다운로드 링크는 **미확인**. 현재 시안은 해당 값을 추측하지 않습니다.
- 교육용 공통 계정 비밀번호는 공개 페이지에 표시하지 않습니다.
- VOD 4편과 새로운 Classroom 실습 파일은 공개 링크가 확정될 때 연결합니다.
- 진행 체크는 브라우저 localStorage에만 저장되며 실제 Pi 상태를 자동 확인하지 않습니다.
- `:5000`은 해당 서버가 별도 실행 중일 때만 접속 가능한 주소입니다.

## 배포 원칙

1. 검토용 GitHub 브랜치/PR로만 올립니다.
2. 사용자가 승인하면 `master`에 반영하는 작업을 별도로 진행합니다.
3. `master` 반영 시 기본 `index.html`을 v2로 교체하거나 리다이렉션할지 결정해야 합니다.
