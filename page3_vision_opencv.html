STEP 7 & 8. Picamera2 및 OpenCV 라이브러리 설치

OpenCV (Open Source Computer Vision)란?

이미지와 영상을 다루는 대표적인 오픈소스 비전 라이브러리입니다. 색상 공간 변환(RGB -> HSV), 가장자리(Edge) 검출, 객체 추적, 얼굴 인식, 딥러닝 모델 프레임 입력 변환 등 2,500개 이상의 강력한 비전 알고리즘을 제공합니다.

bash - install_vision.sh 
# 1) Picamera2 카메라 제어 모듈 설치
pi@raspberrypi:~ $sudo apt install -y python3-picamera2

# 2) OpenCV 비전 라이브러리 설치
pi@raspberrypi:~ $sudo apt install -y python3-opencv
OpenCV 실시간 비전 스트리밍 파이썬 예제
python - camera_opencv_stream.py 
from picamera2 import Picamera2
import cv2

picam2 = Picamera2()
picam2.configure(picam2.create_preview_configuration(main={"size": (640, 480)}))
picam2.start()

print("비전 창을 종료하려면 'q' 키를 누르세요.")

while True:
    frame = picam2.capture_array()
    
    # RGB -> BGR 색상 변환 (OpenCV 표준)
    frame_bgr = cv2.cvtColor(frame, cv2.COLOR_RGB2BGR)
    
    # 화면 안내 텍스트 그리기
    cv2.putText(frame_bgr, "AI Robot Master Vision", (20, 40),
                cv2.FONT_HERSHEY_SIMPLEX, 0.8, (0, 255, 0), 2)
    
    cv2.imshow("Camera Vision Window", frame_bgr)
    
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cv2.destroyAllWindows()
picam2.stop()
