6강_리눅스와 명령어 (Google Presentation)

6강 새창으로 보기
리눅스 주요 명령어 대백과
pwd

Print Working Directory
현재 작업 중인 폴더의 전체 경로를 출력합니다.

ls / ls -a / ls -l

List
현재 폴더 내 모든 폴더 및 파일 리스트 출력 (`-a`: 숨긴파일 표시, `-l`: 자세히, `ls *.cfg`: cfg 파일만 검색).

mkdir [폴더명]

Make Directory
현재 디렉토리에 새로운 폴더를 생성합니다.

cd [경로] / cd ..

Change Directory
디렉토리 이동 (`cd`: 홈 경로 이동, `cd ..`: 상위 폴더 이동).

touch [파일명]

Create Empty File
0 바이트 크기의 빈 파일(예: `touch abc.txt`)을 즉시 생성합니다.

rm [파일명] / rm -rf [폴더]

Remove
파일 및 디렉토리 삭제 (`rm -f`: 묻지 않고 삭제, `rm -rf`: 폴더 및 하위 항목 강제 전부 삭제).

sudo

SuperUser Do
최고 관리자(root) 권한으로 시스템 명령어를 실행합니다.

apt update / apt upgrade

Advanced Packaging Tool
소프트웨어 리스트 인터넷 최신화 (`sudo apt update`) 및 프로그램 최신 버전업 (`sudo apt upgrade`).

clear

Clear Screen
복잡해진 터미널 화면을 깨끗하게 지웁니다.

exit

Exit Session
현재 접속된 터미널 창 및 SSH 세션을 종료합니다.

리눅스 명령어 직접 따라해보기 (Terminal Practice)
bash - linux_practice.sh 
# 1) 현재 위치 확인
pi@raspberrypi:~ $pwd

# 2) test_folder 생성 및 이동
pi@raspberrypi:~ $mkdir test_folder
pi@raspberrypi:~ $cd test_folder

# 3) 빈 파일 생성 및 목록 확인
pi@raspberrypi:~/test_folder $touch robot.txt
pi@raspberrypi:~/test_folder $ls -la

# 4) 상위 디렉토리로 돌아와서 테스트 폴더 삭제
pi@raspberrypi:~/test_folder $cd ..
pi@raspberrypi:~ $rm -rf test_folder
