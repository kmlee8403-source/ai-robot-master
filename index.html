1장. 라즈베리파이 개요 및 공식 OS (Bullseye 32bit) 준비

왜 이것을 배울까요? (Why Learn This?)
인공지능 로봇을 만들기 위해서는 일반 PC처럼 거대하고 전기를 많이 먹는 컴퓨터 대신, 손바닥 크기의 초소형·저전력 고성능 컴퓨터가 필요합니다. 라즈베리파이는 AI 로봇의 "두뇌" 역할을 담당하여 모터, 카메라, AI 가속기를 통합 제어합니다!
라즈베리파이의 원리와 하드웨어 스펙

영국 라즈베리파이 재단이 개발한 카드 크기 초소형 싱글 보드 컴퓨터(SBC)로, 가격이 저렴하고 확장성이 뛰어나며 다양한 운영체제를 지원합니다.

라즈베리파이 대표 모델군

• Pi 500+ / 400: 키보드 일체형 보드
• Pi 4B / 5: 카드 크기 대표 표준 보드 (우리 실습 장비)
• Zero 2W: 초소형 보드 (공간 제약형)

대표 응용 프로젝트 사례

1) 냉장고 이미지 관리: 식품 촬영 후 사진 전송
2) 웹캠 OCR 계산기: 손글씨 숫자/기호 추출 계산
3) 자율주행 AI 로봇: 본 교육 과정 완성 모델!

🖥️ 라즈베리파이 4B 하드웨어 스펙 & 운영체제(OS)

  • 하드웨어 사양: Quad-core 1.5GHz ARM CPU, 4GB RAM, USB 3.0(2개)/2.0(2개), Micro-HDMI(듀얼), Wi-Fi, Bluetooth 5.0, 40핀 GPIO.
  • SD 카드 필수: 본체 내부에 기본 OS가 포함되어 있지 않으므로 Micro SD 카드에 OS를 저장하여 삽입해야 작동합니다.
  • 다양한 OS 가용성: Raspberry Pi OS (공식 데비안 기반), Ubuntu (서버/클라우드), RetroPie (클래식 게임 에뮬레이터), LibreELEC (KODI 미디어 센터).

2장. Imager 설치 & 학생별 호스트명 (pi**) 사전 설정

왜 이것을 배울까요? (Why Learn This?)
한 교실에서 20~30명의 학생들이 동시에 라즈베리파이를 켜면, 기본 이름(`raspberrypi`)이 같아서 서로 남의 로봇에 접속하는 혼선이 일어납니다! 본인의 라즈베리파이에 부여받은 교구 번호(`pi01`, `pi02` ...)를 명확하게 지정해야 내 로봇을 무선/유선으로 안전하게 제어할 수 있습니다.
핵심 개념 요약
  • mDNS (Multicast DNS): Complex한 숫자로 된 IP 주소 대신 `pi01.local` 처럼 쉬운 이름으로 로봇을 자동 찾아주는 네트워크 기술입니다.
  • Imager 고급 옵션 (Ctrl+Shift+X): 라즈베리파이에 모니터와 키보드를 꽂지 않고도 부팅 전 계정과 SSH를 사전 설치하는 스마트 플래싱 기술입니다.
2. Raspberry Pi Imager 다운로드 & 학생 계정 설정

3장. 노트북 - 라즈베리파이 USB to Ethernet 다이렉트 연결

[그림 3-1] 노트북과 라즈베리파이 1:1 다이렉트 랜선 연결 구조도
왜 이것을 배울까요? (Why Learn This?)
로봇 개발 현장이나 모니터/키보드가 없는 외부 실습실에서는 "헤드리스(Headless) 원격 제어"를 사용합니다. 노트북과 로봇을 랜선 하나로 1:1 직접 연결하면 무선 와이파이 간섭 없이 가장 빠르고 안정적인 통신 망을 구축할 수 있습니다!
1:1 하드웨어 연결 순서:
1. 라즈베리파이에 SD 카드를 삽입하고 전원(5V 3A)을 연결합니다.
2. 랜선의 한쪽은 라즈베리파이 랜포트에, 반대쪽은 USB to Ethernet 어댑터에 꽂아 노트북 USB 포트에 연결합니다.
3. 라즈베리파이가 부팅되는 동안 약 1~2분 기다립니다.

4장. 윈도우11 인터넷 연결 공유 (ICS) & 어댑터 IP 세팅

왜 이것을 배울까요? (Why Learn This?)
라즈베리파이가 무선 와이파이 안테나 없이도 인터넷 패키지(`apt install`)를 다운로드하고 내 노트북과 원활하게 통신하려면, 노트북의 와이파이 인터넷을 랜선 어댑터로 공유(ICS)해줘야 합니다. 이렇게 하면 노트북 USB 어댑터 주소가 자동으로 192.168.137.1로 세팅됩니다!
[실습실 필수] 윈도우11 인터넷 연결 공유 (ICS) 설정 순서

노트북 Wi-Fi 인터넷을 라즈베리파이 랜선으로 공유하기

  • 키보드의 Win + R 키를 누른 후 ncpa.cpl 입력 ➔ [네트워크 연결] 창 열기
  • 인터넷이 연결된 노트북의 Wi-Fi (무선 랜) 어댑터 마우스 우클릭 ➔ 속성 (Properties) 클릭
  • 상단 [공유 (Sharing)] 탭 선택
  • "다른 네트워크 사용자가 이 컴퓨터의 인터넷 연결을 통해 연결할 수 있도록 허용" 체크박스 체크!
  • [홈 네트워크 연결] 드롭다운에서 연결된 USB Ethernet 어댑터(예: Ethernet 2) 선택 후 확인 클릭
  • * 인터넷 공유 설정 시, 윈도우가 노트북 USB 어댑터 IP를 192.168.137.1로 자동 구성합니다.

USB 이더넷 어댑터 IP 확인 방법

  • USB Ethernet 어댑터 우클릭 ➔ 속성 ➔ TCP/IPv4 더블클릭
  • IP 주소가 192.168.137.1 / 서브넷 마스크 255.255.255.0 인지 확인하면 준비 완료!

9장. Build HAT 하드웨어 이론 & 모듈 설치 및 디바이스 검증

[그림 9-1] 라즈베리파이 + BuildHAT + 8V 전원 + 레고 SPIKE 모터/센서 하드웨어 결합 구조도
왜 이것을 배울까요? (Why Learn This?)
라즈베리파이 자체의 일반 PIN(3.3V/5V)으로는 레고 모터 구동에 필요한 고전압(8V) 및 빠른 엔코더 측정 신호를 직접 다룰 수 없습니다. Build HAT은 이 두 세계를 이어주는 전용 스마트 변환 다리 역할을 수행합니다!
Build HAT 변환 메커니즘과 SPIKE 부품

RP2040 마이크로컨트롤러

Build HAT 보드 자체에 RP2040 칩이 탑재되어 라즈베리파이 CPU 부하 없이 모터 엔코더와 센서 신호를 실시간 처리합니다.

8V DC 전원 필수 인가

모터 구동에는 8V 4A DC 외부 전원이 공급되어야 하며, Build HAT이 라즈베리파이 보드에도 5V 전원을 안정적으로 전달합니다.

10장. 파이썬으로 LEGO SPIKE 모터 및 센서 제어 함수

왜 이것을 배울까요? (Why Learn This?)
파이썬 프로그래밍 코드를 통해 물리 세계의 로봇 모터를 움직이고, 센서로 환경 데이터를 읽어들입니다. 모터 내장 광학 엔코더의 각도 실시간 피드백(`get_position()`)으로 오차 없는 정밀 주행을 구현해봅니다.
Build HAT 파이썬 모터 및 센서 제어 함수 명세
구분 함수 및 구문 동작 설명 및 동작 예시
지속 회전 motor.run(speed) 속도(-100 ~ 100)로 지속 회전 (`motor.stop()` 명령 전까지 계속 회전)
시간 회전 motor.run_for_seconds(초, speed) 지정한 초 동안 회전 후 자동 정지 (예: `run_for_seconds(3, speed=70)`)
각도 회전 motor.run_for_degrees(각도, speed) 지정한 각도(°)만큼 회전 (예: `360`=1바퀴, `180`=반 바퀴)
엔코더 각도 읽기 motor.get_position() 모터의 모터축 현재 각도(-180° ~ 180°) 정밀 측정 피드백
모터 정지 옵션 motor.stop(stop_action="...") "brake": 즉시 급정거 | "coast": 관성으로 자연스럽게 정지
거리센서 측정 dist.get_distance() 감지된 장애물과의 거리를 cm 단위 수치로 반환 (예: `12.5` cm)
python - test_motor_and_sensor.py 
from buildhat import Motor, DistanceSensor
import time

motor_a = Motor('A')
dist_sensor = DistanceSensor('C')

dist_sensor.on()
motor_a.run(50)

for _ in range(10):
    current_pos = motor_a.get_position()
    current_dist = dist_sensor.get_distance()
    print(f"[엔코더 각도]: {current_pos}° | [장애물 거리]: {current_dist}cm")
    time.sleep(0.3)

motor_a.stop(stop_action="brake")
dist_sensor.off()

12장. 올인원 센서 퓨전(Sensor Fusion) 자율주행 AI 로봇 완성

왜 이것을 배울까요? (Why Learn This?)
우리가 만든 로봇이 시각(Coral TPU AI 카메라) + 환경감지(초음파 거리) + 물리충돌(힘센서) 데이터 신호를 통합 판단하는 **센서 퓨전(Sensor Fusion) 제어 알고리즘**을 완성합니다!
python - ai_robot_master_main.py (센서 퓨전 파이프라인) 
from buildhat import MotorPair, DistanceSensor, ForceSensor
from pycoral.utils.edgetpu import make_interpreter
import time

# 1. Coral TPU 인공지능 추론 모델 로드
model_path = 'coral/pycoral/test_data/mobilenet_v2_1.0_224_inat_bird_quant_edgetpu.tflite'
interpreter = make_interpreter(model_path)
interpreter.allocate_tensors()

# 2. 로봇 하드웨어 액추에이터 및 멀티 센서 정의
pair = MotorPair('A', 'B')
dist_sensor = DistanceSensor('C')
force_sensor = ForceSensor('D')

dist_sensor.on()
print("🤖 AI 로봇 마스터 센서 퓨전 자율주행 출발!")
pair.start(speedl=30, speedr=30)

try:
    while not force_sensor.is_pressed:
        distance = dist_sensor.get_distance()
        
        # [센서 퓨전 1단계] 초음파 센서로 근접 장애물 감지 시 안전 후진 및 회전
        if 0 < distance < 15:
            pair.stop()
            print(f"⚠️ 장애물 발견 ({distance}cm)! 회전 회피 실행")
            pair.run_for_seconds(1, speedl=-30, speedr=-30)
            pair.run_for_degrees(180, speedl=40, speedr=-40)
            pair.start(speedl=30, speedr=30)
            
        time.sleep(0.1)

except KeyboardInterrupt:
    pass

pair.stop()
dist_sensor.off()
print("🛑 자율주행 안전 종료 완료.")
