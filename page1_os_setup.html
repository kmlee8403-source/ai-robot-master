1장. 라즈베리파이 이해하기 & OS Setup

[1강 슬라이드 연동] 라즈베리파이 하드웨어 개요, Bullseye 32bit OS 설치, PuTTY/VNC 원격 접속 및 기본 환경 설정 단원입니다.

1강. 라즈베리파이 이해하기 (Google Presentation)

1강 새창으로 보기
1 Raspberry Pi OS (Legacy, 32bit) Bullseye Standard 다운로드

Coral TPU(Edge TPU) 파이썬 라이브러리 드라이버와의 완전한 호환성을 보장하기 위해 Debian Bullseye 32-bit Standard 버전을 사용합니다.

⚠️ 주의: 최신 Bookworm OS(64bit)에서는 PyCoral 라이브러리 의존성 문제가 있으므로 본 실습에서는 반드시 Bullseye 32bit OS를 다운로드합니다.
Raspios Bullseye 32bit OS 이미지 다운로드 (.img.xz)
2 Raspberry Pi Imager 프로그램 다운로드 및 SD카드 플래싱

Imager 실행 후 [CHOOSE OS] -> [Use custom]을 누르고 STEP 1에서 받은 OS 이미지 파일 선택 후 SD 카드에 써줍니다.

💡 고급 설정 (Ctrl + Shift + X): SSH 활성화, ID/비밀번호(pi / raspberry), 와이파이 SSID를 미리 입력해두면 원격 접속이 훨씬 편리해집니다.
Raspberry Pi Imager 다운로드 (imager-1.9.6.exe)
3 PuTTY SSH 원격 접속 및 raspi-config 환경 설정

PuTTY 프로그램으로 라즈베리파이 IP에 SSH(Port 22)로 접속 후 하드웨어 인터페이스를 설정합니다.

bash - raspi_config.sh 
pi@raspberrypi:~ $sudo raspi-config

raspi-config 설정 핵심:

1. 3. Interface Options -> I3 VNC -> <Yes>

2. 3. Interface Options -> I6 Serial -> 1번(login shell) <No> / 2번(hardware serial) <Yes> (BuildHAT 통신 필수!)

3. Finish -> sudo reboot

PuTTY 다운로드 공식 페이지
4 Real VNC Viewer GUI 접속, 이더넷 고정 IP & 한글 패치

VNC Viewer로 라즈베리파이 바탕화면에 접속하고 유선 이더넷 고정 IP 및 한글 입출력 폰트를 세팅합니다.

conf - /etc/dhcpcd.conf (고정 IP) 
# sudo nano /etc/dhcpcd.conf 맨 아래 추가
interface eth0
static ip_address=192.168.137.100/24
nogateway
Real VNC Viewer 다운로드 (VNC-Viewer-7.15.1.msi)
