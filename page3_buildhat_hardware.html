Build HAT의 핵심 하드웨어 구조

Build HAT(Hardware Attached on Top)은 라즈베리파이가 LEGO® Technic™ / SPIKE™ 모터 및 센서를 직접 조작할 수 있도록 신호를 변환해주는 전용 온보드 스마트 확장 보드입니다.

온보드 RP2040 마이크로컨트롤러

Build HAT 상에는 라즈베리파이 전용 RP2040 칩이 탑재되어 있어, 모터의 실시간 고속 엔코더 펄스 수신 및 PWM 구동 신호를 라즈베리파이 CPU의 부하 없이 독립 처리합니다.

8V 4A DC 외부 전원 공급 어댑터

LEGO 모터와 고성능 비전/거리 센서는 많은 전력을 소비합니다. Build HAT 전용 8V 어댑터는 모터에는 8V 전원을, 라즈베리파이에는 5V 3A 정전압 전원을 동시에 공급합니다.

4개 LPF2 포트 & 시리얼 통신

Port A, B, C, D 4개의 LPF2(LEGO Power Functions v2) 6핀 포트를 탑재하였으며, 라즈베리파이와는 `/dev/ttyAMA0` 하드웨어 UART 시리얼 포트로 전송합니다.

buildhat 파이썬 모듈 설치 & 시리얼 디바이스 검증
bash - buildhat_install.sh 
# 1) BuildHAT 파이썬 라이브러리 설치
pi@raspberrypi:~ $sudo pip3 install buildhat

# 2) BuildHAT 하드웨어 시리얼 포트 연결 확인
pi@raspberrypi:~ $ls -l /dev/serial*

# 정상 출력: /dev/serial0 -> ttyAMA0 심볼릭 링크 확인!
