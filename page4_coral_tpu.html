Google Coral USB Accelerator란?

Google이 개발한 초고속 AI 신경망 가속 코프로세서입니다. 초당 4조 번(4 TOPS)의 연산을 수행하며, 라즈베리파이 CPU만으로는 초당 2~3프레임에 불과한 딥러닝 추론 속도를 **초당 100프레임 이상**으로 가속해줍니다.

반드시 라즈베리파이 4의 **파란색 USB 3.0 포트**에 연결해야 합니다.

bash - install_coral.sh 
# 1) Coral APT 저장소 등록 및 GPG 키 추가
pi@raspberrypi:~ $echo "deb https://packages.cloud.google.com/apt coral-edgetpu-stable main" | sudo tee /etc/apt/sources.list.d/coral-edgetpu.list
pi@raspberrypi:~ $curl https://packages.cloud.google.com/apt/doc/apt-key.gpg | sudo apt-key add -

# 2) Edge TPU C/C++ 런타임 라이브러리 설치
pi@raspberrypi:~ $sudo apt-get update
pi@raspberrypi:~ $sudo apt-get install -y libedgetpu1-std

# 3) PyCoral 파이썬 API 설치
pi@raspberrypi:~ $sudo apt-get install -y python3-pycoral
STEP 13. Edge TPU 이미지 분류 모델 데모 실행

MobileNet V2 딥러닝 모델로 새(Parrot) 사진을 3.1ms(초당 300회)의 전광석화 같은 속도로 분류해봅니다.

bash - run_coral_demo.sh 
# 1) 예제 코드 및 모델 다운로드
pi@raspberrypi:~ $mkdir coral && cd coral
pi@raspberrypi:~/coral $git clone https://github.com/google-coral/pycoral.git
pi@raspberrypi:~/coral $cd pycoral
pi@raspberrypi:~/coral/pycoral $bash examples/install_requirements.sh classify_image.py

# 2) Coral TPU 이미지 분류 데모 실행
pi@raspberrypi:~/coral/pycoral $python3 examples/classify_image.py \
  --model test_data/mobilenet_v2_1.0_224_inat_bird_quant_edgetpu.tflite \
  --labels test_data/inat_bird_labels.txt \
  --input test_data/parrot.jpg

올인원 자율주행 AI 로봇 마스터 연동 완성 코드

Coral TPU AI 비전 객체 인식 + BuildHAT 2개 모터 주행 + 거리센서 장애물 탐지 + 힘센서 비상정지 통합 코드입니다.

python - ai_robot_master_main.py 
from buildhat import MotorPair, DistanceSensor, ForceSensor
from pycoral.adapters import common, classify
from pycoral.utils.edgetpu import make_interpreter
from picamera2 import Picamera2
import cv2, time

# 1. Coral Edge TPU AI 모델 초기화
model_path = 'coral/pycoral/test_data/mobilenet_v2_1.0_224_inat_bird_quant_edgetpu.tflite'
interpreter = make_interpreter(model_path)
interpreter.allocate_tensors()

# 2. BuildHAT 센서 & 모터 초기화
pair = MotorPair('A', 'B')       # 구동 모터 2개
dist_sensor = DistanceSensor('C') # 초음파 거리 센서
force_sensor = ForceSensor('D')   # 비상 정지 센서

dist_sensor.on()
print("🤖 AI 로봇 마스터 자율주행 시작!")

pair.start(speedl=30, speedr=30)

try:
    while not force_sensor.is_pressed:
        distance = dist_sensor.get_distance()
        
        # 장애물 발견 시 자동 회피
        if 0 < distance < 15:
            pair.stop()
            pair.run_for_seconds(1, speedl=-30, speedr=-30)
            pair.run_for_degrees(180, speedl=40, speedr=-40)
            pair.start(speedl=30, speedr=30)
            
        time.sleep(0.1)

except KeyboardInterrupt:
    pass

pair.stop()
dist_sensor.off()
print("🛑 로봇 정지 완료.")
